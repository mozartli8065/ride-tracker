# 北海岸 101K

給 2026-11-22（日）這趟騎行用的手機網頁。從大稻埕碼頭沿淡水河、關渡、紅樹林、淡水，上臺 2 經淺水灣、白沙灣、富基漁港、石門洞到石門草里，再原路回來，大約 101 公里。

畫面上最大的數字是你比計畫**超前或落後幾分鐘**（綠色超前、紅色落後），旁邊是差幾公里。另外有已騎／剩餘、現在速度、移動均速、這一刻計畫上該到的里程、下一站的計畫時間和依目前速度的到達時間，以及預計回到碼頭的時間。若預計會晚於 **16:30**，會標成安全線警告，並提示可以在回程的紅樹林站收車搭捷運。

不需要建置、不需要後端、不需要 API key。定位用瀏覽器的 GPS；路線座標已經寫在 `route.js` 裡。

## 在電腦上開

```bash
python3 -m http.server 8741
```

瀏覽器打開 <http://127.0.0.1:8741>。

定位只有在 HTTPS 或 localhost 才會給。出門前先到「設定」打開**示範模式**，用假定位沿路線跑完全程，確認超前／落後的數字。示範速度和時間倍率（1× 到 600×）可以調；600× 大約四十秒跑完。

邏輯測試（不開瀏覽器）：

```bash
node test_engine.js
```

## 放到手機，並且在訊號差時還開得了

1. 把這個資料夾拖到 [Netlify Drop](https://app.netlify.com/drop)，會得到一個 `https://….netlify.app` 網址。這是最省事的公開 HTTPS。
2. iPhone 用 Safari 打開那個網址，點分享 → **加入主畫面**。Android 用 Chrome，選「加到主畫面」。
3. 在有網路的地方先開一次，服務工作人員會把頁面存下來。之後圖資載不出來，里程和超前落後仍然算。

也可以用任何靜態空間（Cloudflare Pages、GitHub Pages、自己的 nginx）。不要用 `file://` 直接開檔案，手機不會給定位。

## 預設時刻（台北時間）

釘住的只有休息：08:00 出發、淡水站 10 分、白沙灣 10 分、草里 11:30 到／13:00 走、15:50 回到碼頭。去程一律約 15.9 km/h，回程一律約 17.8 km/h。關渡、淺水灣、回程的淺水灣和淡水是用這個配速算出來的，沒有硬對紙本時刻。回程咖啡預設不加。

勾選回程咖啡後，淺水灣（回）停到 14:10，終點約 16:20。16:30 是安全線，日落 17:04。紙本若要改出發時間，或按「我現在出發」，整份時刻一起平移。取消「計入計畫休息」會拿掉淡水 10 分、白沙灣 10 分和草里午餐 90 分。午餐預設停在草里；若改去富基吃，折返後自己停，計畫仍以 13:00 離開折返點計算。

出發時間、休息開關、已騎里程和示範進度存在這台手機的 localStorage，重新整理或瀏覽器被關掉不會清掉。

往返重疊的路段用「上次走到哪」往前接，不會因為去程和回程是同一條路就跳錯邊。在折返點按「我已折返」也可以手動切到回程。

## 路線怎麼來的

`route.js` 是 BRouter（trekking）沿著 OpenStreetMap 的自行車道和臺 2 算出來的，再在程式裡把去程反轉成回程。單程約 50.5 km，來回約 100.9 km。富基漁港那一段有繞進港區。
